# SoundPlayer
{: .no_toc }

SoundPlayers allow you to play a sound on Trigger. It requires a folder named Sounds where it will play the sounds inside of it at random. See [PlaySoundInstance]({% link CLIMBABLES/UtilityModules/behaviorutil.md%}#playsoundinstance)
